# nocx 0.7.0

0.7 makes the terminal feel more like a place to work. Text entered through an input method arrives as one intent, full-screen programs fit their panes, shell integration reaches beyond zsh, and an update can restart the installed app without losing the coordinator that keeps sessions alive.

## Your terminal gets a steadier hand

An input method can commit one character in several pieces. nocx now treats one composition commit as one text intent, rather than inserting duplicate characters (#432).

Full-screen programs use the pane's available width, including after a restored tab returns. The terminal also keeps its screen mappings tied to the sessions that own them, so finished sessions release their mappings (#460, #437, #471).

The bundled Nordwand Mono font gives nocx a terminal typeface that ships with the app (#479). Mouse gestures over the live grid no longer turn small pointer motion into a click or drag; selection and program mouse reporting follow the existing terminal state (#438, #382).

Image-only clipboard paste now reaches a program as a paste intent, including when bracketed paste mode is active (#412). This delivers the paste event; whether a particular program displays image data depends on that program.

## Fish joins shell integration

Fish is now a supported native shell integration, alongside the existing shells. Its startup path, command lifecycle and prompt hand-off are covered by the native Fish journeys in CI (#465, #492).

## Updates keep your sessions

An update can keep a protocol-compatible coordinator alive, then launch the installed app when you choose Restart now. Your running sessions do not have to end just because the app window is replaced (#456, #493).

The update channel setting selects which manifest the updater checks. A failed check is visible, and the update notice gives you an action instead of leaving you to guess what happened (#454, #450, #455).

## More fixes around the edges

- A shell that never completes its startup handshake becomes a usable plain terminal after the defined bound, instead of waiting forever (#426).
- The numeric keypad's Enter key submits like Return (#420).
- A tab opened in the home directory is named `~` (#453).
- The About window shows nocx's own copyright and version information (#451, #455).
- A restored window returns to its previous size, and a confirmed backend layout is not undone by a stale renderer read (#458, #459).
- A failed paste that wrote nothing returns its message to the queue (#397).
- The Linux AppImage waits until Wails has built a window before raising it (#430).
- The v0.7 renderer memory work releases screen mappings with their sessions and measures the renderer during terminal use (#471, #490).

## What this release does not include

Signed nightly builds are deferred to v0.8 (#489). This release does not claim that every terminal program renders image clipboard content; nocx forwards the paste intent, and application support varies. Some CI timing and flake findings were also moved to v0.8 (#495).
