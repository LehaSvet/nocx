# nocx 0.7.0

0.7 makes the terminal behave the way you already expect, and makes an update stop
costing you your work.

## Typing through an input method stops doubling characters

If you type Chinese, Japanese or Korean through an input method, one character you
committed could arrive as several and the line came out with duplicates. A commit now
lands once, so the line says what you typed.

## Fish works out of the box

Fish joins the shells nocx understands. The pane knows when your prompt is ready and
what your commands did, the same way it does for zsh and bash. Your Fish configuration,
history and prompt functions behave as they do in any other terminal, and a version
nocx has not verified still opens as a plain working terminal instead of a broken one.

## Restart now installs the update and your running sessions survive

Choosing Restart now installs the new version and starts it, and the sessions you had
running are still there afterwards. A session no longer has to end because the app was
replaced underneath it.

Update checks also follow the channel you picked in Settings, a check that fails tells
you it failed instead of looking like "no update", and the update notice offers you an
action rather than a sentence.

## Nordwand Mono ships with the app

Settings → Terminal → Font family now offers **Nordwand Mono**, without installing a
font or downloading one at run time. Regular, italic, bold and bold italic are included.
System default still restores the theme's original font.

## Memory stays flat through a long day

Opening and closing sessions over a long day used to keep the memory those sessions had
held. Closing a session now gives it back, so the app's memory stops climbing as the day
goes on.

## One identity on every platform

nocx now calls itself `dev.nocx` everywhere: the name macOS records for the app, the name
its permission prompts attach to, and the name the Linux launcher uses. Updating from an
earlier build asks you once more for notification permission, and the window's page storage
starts empty, so a warning you had dismissed once can ask again. Your settings, vault,
connections and window size come with you.

## An agent you start in a local shell can use nocx's tools

Starting an agent in a local pane used to leave it without nocx's tools: the shell was
handed the credential and dropped it. The agent now receives it and can use nocx's tools
while it runs, and the credential never appears in your shell's startup script.

## The small things

- A restored tab's program fits the pane it comes back into, instead of drawing for the
  size it had before.
- The window reopens at the size you left it.
- A pane you just opened is no longer closed by a late layout update.
- A program that owns the pane fills its full width, including in the first moments of a
  fresh shell.
- A tab opened in your home directory is named `~`, like every other terminal.
- The About window shows nocx's own copyright, not a placeholder.

## What 0.7.0 does not include

Signed nightly builds come in 0.8.
