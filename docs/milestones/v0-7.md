# v0-7 — nocx carries the work being fixed now

Charter approved by the owner on 2026-10-22: “everything we are fixing now goes into 0.7.” Status is in the tracker, not here: `scripts/feature-status.sh nocx-1ebrs`.

## What ships

The live 0.6 work now being fixed ships as 0.7 carryover, alongside four selected outcomes: the shipped 0.6.1 duplicate-character regression stays fixed; compatible coordinator updates preserve live sessions; signed nightlies can be selected and promoted without rebuilding; and native fish integration works on macOS and Linux. These outcomes are independent; their order is not a dependency.

## Outcomes

- **O1: A person no longer hits the post-0.6.1 duplicate-character regression** (`nocx-1ebrs.64`). **Check:** the owner found `.38` on shipped 0.6.1; merged PR #432 fixed it with a keyboard/IME regression test. The issue evidence says one intent produces one character. `Serves: shipped nocx works without duplicate input.`
- **O2: A commit-only update keeps the coordinator and live sessions compatible** (`nocx-1ebrs.65`). **Check:** a window restarts onto a newer commit with compatible discovery and protocol/RPC while preserving live sessions; a real incompatibility replaces the coordinator and reports session loss. Tasks: `.53`, `.54`, `.55`, `.57`. `Serves: reliable local terminal sessions.`
- **O3: A person can opt into signed nightlies and promote a tested nightly without rebuilding** (`nocx-1ebrs.66`). **Check:** a daily run publishes signed macOS and Linux artifacts only when main moves; updater defaults to stable and can select nightly; promotion preserves exact artifact bytes and updates the tap. Tasks: `.35`, `.35.1`–`.35.6`, `.52`. `Serves: local updates users can verify and control.`
- **O4: A person can use native fish shell integration in nocx** (`nocx-1ebrs.67`). **Check:** fish journeys run, not skip, in `ci-mac` and `ci-linux`, and all 12 CI jobs are green. Task `.58`; unsupported journeys are explicit. `Serves: shell integration across supported shells.`

The four outcome epics remain children of the existing `nocx-1ebrs` feature root. Its DONE WHEN remains unchanged: a person installs nocx with one brew command from our own tap, and it opens without a manual quarantine step.
